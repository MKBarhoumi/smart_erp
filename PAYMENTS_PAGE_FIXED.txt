THE PROBLEM
═══════════
The /payments page was showing a blank white screen with this error in the browser console:
  
  Uncaught TypeError: Cannot read properties of null (reading 'id')
      at Index.tsx:127:74

This happened because some Payment records in the database didn't have valid 
relationships to invoices (orphaned foreign keys), causing null values in the 
response array.

THE SOLUTION
════════════

1. BACKEND FIX - PaymentController.php
   ───────────────────────────────────
   Added a crucial database constraint to filter out invalid payments:
   
   Line 25: ->whereHas('oldinvoice')
   
   This ensures ONLY payments with valid invoices are returned from the database.
   Any payment records pointing to deleted invoices are automatically filtered out.

2. FRONTEND FIX - Payments/Index.tsx  
   ──────────────────────────────────
   Added defensive null checking in two places:
   
   Lines 58 & 62 (Stats Section):
   Before: payments.data.filter(p => p.method === 'bank_transfer')
   After:  payments.data.filter(p => p && p.method === 'bank_transfer')
   
   Lines 121-122 (Payment Table):
   - Filter: payments.data.filter(p => p !== null)
   - Safety: if (!payment || !payment.oldinvoice) return null;

3. FRONTEND REBUILD
   ─────────────────
   Frontend was rebuilt successfully with all fixes applied.
   Build completed: ✓ built in 2.10s
